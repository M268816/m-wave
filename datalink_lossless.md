# PI Datalink loss-less search and collection.

Citrix: Search for data.
Citrix: Save data as temp.csv, yes on the citrix vm.
Citrix: File>Open>Recent
Citrix: Right click temp.csv that was just saved.
Citrix: Open with>Notepad
Notepad: Copy all csv data.
Local Excel: Paste>Use Text import Wizard...
Local Excel: Check "Delimited"
Local Excel: Check "My data has headers".
Local Excel: Next>Check "Comma" only.
Local Excel: Finish
Citrix: Right click temp.csv.
Citrix: Delete.

Security Data has no errors!
