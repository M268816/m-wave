
First
    - Be sure to have all Excel instances closed. This application uses its own
      instances of excel to format any appended data without disturbing any formatting
      or settings.

    - This tool has only guaranteed compatibility with the posted MTL version in the
      configuration section.

Setup
    - Using PI Builder, pull information from the data historian and save the data as a
      comma separated value file.

    - File types can be changed with the "Save As" dialog box.

    - Although not necessary, having the data set cleaned at this stage will have the
      best results. Otherwise, the app will do it's best to clean and filter the data
      during processing.

Instructions
    1. Use the "Pick file" buttons to select a local version of the MTL/CMD and your
      exported PI Builder information.

    2. Use the "Filter" input box if you need to filter for specific data objects. For
       example, filtering for "_LOC_" will help the system remove any unwanted objects
       that may be named "_LOCobject_".

        2.1. WHEN APPENDING DATA - NOT ENTERING FILTERS WILL HAVE THE BEST RESULTS.

    3. Select the table that the information will be appended or compared to.

    4. Select your process type with the radio buttons located next to the progress bar,
       then click the "Process" button to start.

    5. The application will try to catch any errors and either display or prompt any
       exceptions found in the text display or pop-ups.

    6. Logs of the process will be available when the process completes inside of a
       folder that will be formatted with the date, time, and any filters used.

       6.1. example: ../<REPORTS>/<DATETIME>_(<FILTER>)
